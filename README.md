# Basic-Calculator-for-Gold
A simple Gold Calculator app built with Flutter and Dart, designed for calculating the value of gold using the Pakistani gold rate per Tola.

Features
Enter the current gold price per Tola
Enter the gold quantity in Tola
Calculate the total gold value instantly
Simple and beginner-friendly UI
Built using Flutter & Dart
Calculation

Total Gold Value = Gold Price per Tola × Tola Quantity

Example

If the gold rate is Rs. 500,000 per Tola and you enter 2 Tola:

Result = Rs. 1,000,000
